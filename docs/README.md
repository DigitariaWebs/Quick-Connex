## Documentation Standards

- All documentation is written in Markdown
- Code examples include both TypeScript and JavaScript
- Response structures are documented with JSON examples
- Visual guides use ASCII diagrams where helpful
- Quick reference guides are provided for common tasks

## Contributing to Documentation

When adding new features or making changes:

1. Update relevant documentation files
2. Add new documentation files for new systems
3. Update this index when adding new documentation
4. Follow the established documentation patterns
5. Include code examples and response structures
